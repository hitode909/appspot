# 2014 [Speaker Deck: Perlの静的解析入門とPerlリファクタリングツールApp::PRTのご紹介](https://speakerdeck.com/hitode909/perlfalsejing-de-jie-xi-ru-men-toperlrihuakutaringuturuapp-prtfalsegoshao-jie)

# 2015 [Speaker Deck: Perlの上にも三年 〜 ずっとイケてるサービスを作り続ける技術 〜](https://speakerdeck.com/hitode909/perlfalseshang-nimosan-nian-zututoiketerusabisuwozuo-risok-keruji-shu)

話題：AMPの紹介と、はてなブログでの対応方針、技術的な難しいことを紹介

# 発表のコツ

# 自分の話をしよう

- 自分が経験したことや、自分で考え込んだことは実感があり、おもしろい
- 課題は一緒でも、考えた結果どうなるか、は人によって違うし、おもしろい

# 興味のあることを他人に伝えて同志を増やそう

- あなたのこだわりの入門編を作ろう
- 資料を見ながら試せるようにしよう
- 趣味の仲間を増やせるかもしれません
- 高度な専門家のための話をする必要はありません

# 最近驚いたことを話そう

- 今月驚いたこと、今週驚いたこと、YAPCの2日間で驚いたこと、このLT大会で驚いたこと
- どうなると予想していた？次に同じことが起きたら、どうしたい？

# 手抜きをしよう

- 完成と思った時点で完成
- だから、完成の定義を下げれば、完成が早くなる
- typoのあるスライドや、結論がないスライド、画像が抜けたスライドでもいいじゃないですか
- 資料はそこそこに、目の前の人たちと、話し始めよう！
