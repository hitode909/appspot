# 即席LTワークショップのルール

- 1発表3分まで
- この時間に、この会場で、即興で、発表の準備をしてください
- 準備ができたらふせんにタイトルと名前を書いてください（前方にあり）
- 前方に来て発表
- 発表後、ふせんを壁に貼ってください
- 見るだけ、聞くだけ、質問するだけの参加も歓迎。出入り自由

ふせんの写真は今日の記録として、後日インターネットに公開したいと考えています。名前はハンドルネームでもニックネームでも。表に出ると困る書き方はしないでください

# この場のお願い

- 初めての発表、大歓迎です。上手に話すことだけが目的ではありません。あなたならではの視点や、面白いと思ったことを大切にしてください
- 気になることがあれば質問してみましょう。長くなりそうなら、あとで個別にお願いします
- 発表はSNSで紹介されることがあります。オフレコ、公開NGは発表者がアピールしてください
- 事前のレビューを経ていない、考え途中の発表もあります。紹介するときは、文脈を大切にしてください

# 注意
- [YAPC::Japan/Japan.pm - Code of Conduct - Japan Perl Association](https://japan.perlassociation.org/entry/yapc/code_of_conduct)に従ってください
- 多様な人がいるので、最大限の共感をもって聞きましょう、話しましょう。意見が合わない、ではなく、なぜ相手はその意見を持つに至ったのか？と考えてみてほしいです
- 私は写真OKですが、登壇者の撮影やSNSへの発信は本人に確認してください
