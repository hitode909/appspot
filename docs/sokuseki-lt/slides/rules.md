# 第1部：即席LT大会のルール説明

# 即席LT大会のルール

- 3分程度のLT資料を作ってください
- 準備ができたらふせんにタイトルと名前を書いてください（前方にあり）
- 前方に来て発表
- 発表の記録としてふせんを壁に貼ってください

ふせんの写真は今日の記録として、後日インターネットに公開したいと考えています

# 注意
- [YAPC::Japan/Japan.pm - Code of Conduct - Japan Perl Association](https://japan.perlassociation.org/entry/yapc/code_of_conduct)に従ってください
- 多様な人がいるので、最大限の共感をもって聞きましょう、話しましょう。意見が合わない、ではなく、なぜ相手はその意見を持つに至ったのか？と考えてみてほしいです
- 私は写真OKですが、登壇者の撮影やSNSへの発信は本人に確認してください

# ベスト即席LT賞について

なんと、16:10〜のLightning Talksに一名参加できます！
このセッションで即席で作ったLT資料で、本編LTの前座として登場できる可能性があります
15:50ごろからベスト即席LT賞を選出・発表します。発表時に会場にいらっしゃらない場合は順次繰り上げ当選となります

選出はhitode909が独断で、「即席感」や「身の丈感」を軸に判定します
