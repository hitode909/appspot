4資料作成タイム＆発表タイム 25分〜15:50

  • このスライドを映して、資料作成を始めてもらう。このページの URL を伝えると、参加者が手元で道具を使える
  • 会場を歩いて、手が止まっている人に声をかける。下の 4-1〜4-4 から合いそうなものを映すか、手元で開いてもらう
  • できた人から前に出て発表。準備ができたらふせんにタイトルと名前を書き、発表のあとで壁に貼ってもらう
  • 発表が途切れたら 4-5 か、5 時間が余ったらを1つ出す

4-1 ネタが見つからない人へ

切り口は、参加者が手元で開いて1つ引くこともできる。

4-2 資料を手早く作る

穴うめLTはプレゼンツールがない人向け。スマホでも使え、答えを URL にして共有できる。

4-3 話の始め方・終わり方

4-4 縛りを1つ足す

決めることが多くて進まない人に。「次の人はこれで」と会場で引いても遊べる。

4-5 発表と発表のあいだに

発表が途切れたら、はげましの一言か心得を1つ出して、次の人の背中を押す。

5時間が余ったら 1〜3分ずつ

発表と発表のすき間や、発表が出尽くしたときに。どれからでもよい。

5-1 YAPCトーク研究室

過去の YAPC のトークを数えたり並べたりしたもの。「締め切りの日」「何年のトーク？」は会場で見せやすい。

5-2 プレゼンカラオケ

AIが作った初見のスライドを引いて、その場で読みながら3分話す。まず hitode909 が1本やってみせ、「1本やってみます」という人に渡す。

5-3 二軸プロット

発表したタイトルをふせんにして、2本の軸の上に置く。置き場所の正しさより「なぜそこに置いたか」を話す。軸ガチャで、その場限りの軸に替えてもよい。

  • ふせんの壁の写真を撮る
  • 下のスライドで、YAPC の外でも発表しようと呼びかけて締める
