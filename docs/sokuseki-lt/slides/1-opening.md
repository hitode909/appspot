# 即席LTワークショップとは

今この場で、みなさんに資料を作っていただきます
資料ができたら、ただちに、発表してもらいます

# 高スピード化

資料を作るツールが速くなった→今資料を作ろう
技術の変化が速く、情報がすぐ古くなる→今思っていることを直ちに話そう

# 当日の良さ

プレゼンしていると、当日が一番おもしろい

準備を簡単に、話者を増やせればおもしろさを上げられるのではないか
