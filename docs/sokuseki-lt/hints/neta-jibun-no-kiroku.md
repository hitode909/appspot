# 自分の書いたものを読み返す

---

自分の投稿やコミットは、自分についての記録です

---

## SNS の投稿を読み返す

- Slack や X で、この1か月に自分が書いたものを見る
- 長く書いた投稿は、言いたいことがあったとき
- 反応が多かった投稿は、人も気になっていた話

---

## GitHub を見る

- 自分のコミット履歴を、さかのぼって眺める
- スターを付けたリポジトリを見る
- 「なぜスターを付けたか」で1本話せる

---

## カレンダーを見る

- 先週の予定を見る
- 行った場所、出たイベント、はじめての予定
- 予定と予定のあいだに、何かあったかもしれない

---

## 映すときの注意

- 社内の Slack、非公開のリポジトリ、カレンダーは映さない
- 公開されているものでも、ほかの人の名前やアイコンに気をつける
- 話す内容だけを、自分の言葉でスライドに書き直す
