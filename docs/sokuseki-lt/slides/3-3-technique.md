# テクニック編：発表のコツ

# 自分の話をしよう

- 自分が経験したことや、自分で考え込んだことは実感があり、おもしろい
- 課題は一緒でも、考えた結果どうなるか、は人によって違うし、おもしろい

# 興味のあることを他人に伝えて同志を増やそう

- あなたのこだわりの入門編を作ろう
- 資料を見ながら試せるようにしよう
- 趣味の仲間を増やせるかもしれません
- 高度な専門家のための話をする必要はありません

# 最近驚いたことを話そう

- 今月驚いたこと、今週驚いたこと、YAPCの2日間で驚いたこと、このLT大会で驚いたこと
- どうなると予想していた？次に同じことが起きたら、どうしたい？

# 手抜きをしよう

- 完成と思った時点で完成
- だから、完成の定義を下げれば、完成が早くなる
- かわりに全力で喋ろう
- 資料はそこそこに、目の前の人たちと、話し始めよう！
