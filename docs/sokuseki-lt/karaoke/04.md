# cron の気持ち

この資料はAIが作った架空の内容です

---

## cron は毎分起きている

- 毎分、時計を見る
- やることがなければ、また待つ
- 1日に1,440回、同じことを確かめている

---

## 0時0分は混む

- 多くのジョブが 0 0 * * * に置かれる
- 同じ時刻に、みんな動き出す
- cron は何も言わない

---

## 誰も読まないメール

- 出力は、どこかにメールで送られる
- 送り先は、もういない人のこともある
- それでも毎日送られる

---

## まとめ

- cron は、頼まれたことを黙ってやる
- 黙っているので、忘れられる
- 最後に crontab -l を見たのはいつですか
